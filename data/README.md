# Dataset

`rendimiento_estudiantes.csv` is a Spanish-labelled derivative of the **Predict Students' Dropout and Academic Success** dataset from the UCI Machine Learning Repository. Column names and categorical labels were translated into Spanish for the course project.

## Contents

- 4,424 anonymised student records
- 36 input variables and one three-class target (`objetivo`)
- Semicolon-separated values
- Target classes: `abandono`, `matriculado`, and `graduado`
